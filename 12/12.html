PsychoPy Coder

In dieser Einheit beschäftigen wir uns mit dem Python-Code, der jedem PsychoPy-Experiment zugrunde liegt. Auch wenn ein Experiment mit der grafischen Oberfläche Builder erstellt wurde, wird es vor dem Ausführen in ein Python-Script konvertiert. Dieses wird dann von Python ausgeführt. Man kann aber auch direkt ein Python-Script erstellen, um PsychoPy zu verwenden – dies führt in vielen Fällen zu wesentlich kompakterem Code. Als Code-Editor für PsychoPy-Scripts eignet sich der mitgelieferte PsychoPy Coder.

Der Code des Stroop-Experiments

Wenn man in PsychoPy Builder ein Experiment grafisch erstellt hat, kann man den zugehörigen Code über Tools – Compile bzw. durch Klicken auf das Icon “Compile to Python script” erzeugen. PsychoPy Coder öffnet sich dann automatisch mit dem generierten Script.

Tipp

Probieren wir das mit unserem Stroop-Experiment aus der letzten Einheit aus. Dazu vereinfachen wir das Experiment, indem wir die Routine “Feedback” entfernen: Klicken Sie mit der rechten Maustaste auf die Routine und wählen Sie “remove”. Das entsprechende Tab kann ebenfalls geschlossen werden.

Mit einem Klick auf das Icon “Compile to Python script” wird das Experiment dann in ein Python-Script konvertiert. Dieses wird auch gleich mit PsychoPy Coder geöffnet.

Das erstellte Script ist für ein so einfaches Experiment mit fast 500 Zeilen relativ lang. Es enthält viel Code, der für dieses Experiment nicht benötigt wird, beispielsweise import-Anweisungen für Module, die im weiteren Script nicht verwendet werden. Wir werden dieses Script nicht im Detail untersuchen, sondern einfachere Komponenten direkt mit Code erstellen.

Minimales Experiment

Ein minimales PsychoPy-Experiment besteht aus fünf Zeilen Code. Es erzeugt ein leeres Fenster, das für zwei Sekunden sichtbar ist.

from psychopy import core, visual

win = visual.Window(size=[800, 400])
core.wait(2)
win.close()
core.quit()

Obwohl dieses Experiment nichts weiter tut, zeigt es die grundlegende Struktur:

Zu Beginn importiert man alle nötigen Module aus dem psychopy-Paket. Die PsychoPy-Dokumentation enthält eine detaillierte Beschreibung aller vorhandenen Module, wir benötigen hier aber nur die Module core (Basisfunktionen) und visual (visuelle Stimuli).

Danach erstellen wir das Programmfenster, in dem das Experiment läuft. Dazu rufen wir visual.Window auf. Die Funktion erzeugt ein Fenster mit der angegebenen Größe und gibt es zurück; wir weisen diesem Fenster den Namen win zu.

Ab jetzt könnte man alle Stimuli erzeugen, die im Verlauf des Experimentes benötigt werden. Dieses Beispiel enthält jedoch keine Stimuli – es wartet mit core.wait(2) zwei Sekunden. Danach schließen die letzten beiden Zeilen das Programmfenster und beenden das Experiment.

Hinweis

Das Script kann durch Klicken auf das Icon “Run experiment” ausgeführt werden.

Darstellen von Stimuli am Bildschirm

In einem richtigen Experiment verwendet man natürlich diverse Stimuli. Im Folgenden werden wir einige visuelle Stimuli näher betrachten. PsychoPy kann mit den im Modul visual enthaltenen Funktionen eine große Anzahl an unterschiedlichsten visuellen Stimuli erzeugen, wie beispielsweise Text, Formen (Kreise, Rechtecke, Linien), Bilddateien, Muster, usw.

Die Darstellung von visuellen Stimuli am Bildschirm funktioniert wie folgt:

  1. Zunächst wird das Fenster win erzeugt. Darin können später alle Stimuli gezeichnet werden.
  2. Anschließend kann ein Stimulus-Objekt stim erzeugt werden, das dem Fenster zugeordnet ist. Beim Erzeugen des Stimulus kann man sein Aussehen festlegen, etwa Farbe, Position und Orientierung. Alle Eigenschaften eines Stimulus können auch nachträglich im Verlauf des Experimentes geändert werden.
  3. Schließlich wird der Stimulus stim mit der Methode stim.draw() gezeichnet. Das Zeichnen erfolgt zunächst unsichtbar im sogenannten Backbuffer – man kann sich diesen Buffer wie die Rückseite des Bildschirms vorstellen. Alles, was gezeichnet wird, landet zuerst im Backbuffer und ist damit noch nicht sichtbar.
  4. Wenn alle gewünschten Stimuli im Backbuffer gezeichnet sind, wird sein gesamter Inhalt mit win.flip() sichtbar gemacht. Der Backbuffer wird standardmäßig anschließend geleert. Diese Operation ist normalerweise mit der Bildwiederholfrequenz synchronisiert, d.h. der Aufruf von win.flip() wird genau bei der nächsten Bildschirm-Aktualisierung ausgeführt.

Der Vorteil dieser Aufteilung in Backbuffer und Frontbuffer ist, dass alle Stimuli im Backbuffer gemeinsam beim nächsten win.flip() sichtbar werden. Würden die Stimuli direkt nach dem Zeichnen sichtbar, könnten die verschiedenen Komponenten eines Bildes zu leicht unterschiedlichen Zeiten erscheinen.

Unser minimales Experiment können wir nun also mit einem Text-Stimulus wie folgt erweitern:

from psychopy import core, visual

win = visual.Window(size=[800, 400])
text = visual.TextStim(win, "Text\n\n2 Sekunden sichtbar.")
text.draw()  # in den Backbuffer zeichnen (noch unsichtbar)
win.flip()  # sichtbar machen
core.wait(2)
win.close()
core.quit()

Warten auf einen Tastendruck

Wir können nun schon fast einen Instruktionsbildschirm anzeigen – es fehlt nur noch die Möglichkeit, die Instruktionen so lange anzuzeigen, bis die Versuchsperson eine bestimmte Taste (wie beispielsweise die Leertaste) drückt. Die aktuelle PsychoPy-Schnittstelle für Tastatureingaben ist hardware.keyboard.Keyboard. Mit der Methode waitKeys() kann man warten, bis eine Taste gedrückt wird. Mit dem Argument keyList geben wir die erlaubten Tasten als Liste an. Unser Beispiel kann damit wie folgt erweitert werden:

from psychopy import core, visual
from psychopy.hardware import keyboard

win = visual.Window(fullscr=True)
kb = keyboard.Keyboard()
s = """Text Rotation

Press 'left' to rotate the text to the left.
Press 'right' to rotate the text to the right.

Press Space to start!
"""
text = visual.TextStim(win=win, text=s, color="white", height=0.05)
text.draw()
win.flip()
kb.waitKeys(keyList=["space"])
win.close()
core.quit()

Durch die Angabe von keyList=["space"] wird gewartet, bis die Leertaste gedrückt wird. Erst dann wird das Script in der nächsten Zeile fortgesetzt.

Wichtig

kb.waitKeys() blockiert den Programmablauf: Bis eine passende Taste gedrückt wird, wird keine weitere Zeile des Scripts ausgeführt. Das ist für einen Instruktionsbildschirm geeignet.

kb.getKeys() blockiert nicht: Die Methode gibt sofort eine Liste der seit dem letzten Aufruf gedrückten Tasten zurück. Wurde keine Taste gedrückt, ist die Liste leer. Deshalb verwenden wir getKeys() innerhalb von Animations- und Trial-Schleifen, damit Stimuli weiterhin gezeichnet und mit win.flip() angezeigt werden können (siehe Beispiel im nächsten Abschnitt).

Hinweis

Die ältere Schnittstelle event.waitKeys bzw. event.getKeys funktioniert weiterhin, bietet aber weniger präzise Zeitstempel. hardware.keyboard.Keyboard wird für neue Experimente empfohlen: Tastendrücke werden damit asynchron erfasst, und die Reaktionszeit ist direkt über das Attribut .rt verfügbar.

Verwenden einer Schleife

Wir versuchen jetzt, das im vorigen Beispiel beschriebene Experiment umzusetzen. Nach dem Instruktionsbildschirm soll ein Text (nämlich PsychoPy) am Bildschirm angezeigt werden. Wenn man die linke Pfeiltaste drückt, soll der Text nach links rotieren. Drückt man die linke Taste wiederholt, wird die Rotation schneller. Drückt man die rechte Pfeiltaste, verlangsamt die Rotation nach links und man kann den Text dann nach rechts rotieren lassen. Wenn die Leertaste gedrückt wird, soll das Experiment beendet werden.

from psychopy import core, visual
from psychopy.hardware import keyboard

win = visual.Window(fullscr=False)
kb = keyboard.Keyboard()
s = """Text Rotation

Press 'left' to rotate the text to the left.
Press 'right' to rotate the text to the right.

Press Space to start!
"""
text = visual.TextStim(win=win, text=s, color="white", height=0.05)
text.draw()
win.flip()
kb.waitKeys(keyList=["space"])

text.setText("PsychoPy")
text.setHeight(0.15)

rotation = 0
speed = 0

while True:
    keys = kb.getKeys(keyList=["space", "left", "right"])
    if keys:  # eine Taste wurde gedrückt
        if keys[0].name == "space":
            break
        elif keys[0].name == "left":
            speed -= 1
        else:
            speed += 1
    rotation += speed
    text.setOri(rotation)
    text.draw()
    win.flip()

win.close()
core.quit()

Ein neuer Bestandteil in diesem Experiment ist, dass wir den vorhandenen Text-Stimulus text wiederverwenden. Beim Initialisieren zeigen wir zunächst die Instruktionen damit an. Danach setzen wir den Text mit text.setText("PsychoPy") und die Größe mit text.setHeight(0.15) auf andere Werte. Das ist oft schneller als das Erzeugen eines neuen Text-Stimulus und sollte daher in den meisten Fällen bevorzugt werden.

Danach folgt eine Endlosschleife while True. Man erkennt aber schon, dass diese Schleife mit break auch verlassen werden kann, und zwar wenn die Leertaste gedrückt wird.

Die erste Anweisung innerhalb der Schleife gibt eine Liste der gedrückten Tasten zurück. Durch das Argument keyList werden nur die angegebenen Tasten berücksichtigt. Wenn keine Taste gedrückt wurde, ist keys eine leere Liste. Mit if keys: überprüfen wir daher, ob die Liste Einträge enthält. Eine nicht leere Liste wird in einer Bedingung als True interpretiert, eine leere als False.

Jeder Eintrag in keys ist ein KeyPress-Objekt. Der Name der Taste steht im Attribut .name. Wenn die erste gedrückte Taste, also keys[0].name, die linke Pfeiltaste ist, wird die Rotationsgeschwindigkeit speed (anfänglich 0) um 1 verringert. Bei der rechten Pfeiltaste wird speed um 1 erhöht. Die Orientierung rotation des Textes wird durch Addition der aktuellen Rotationsgeschwindigkeit bestimmt. Danach dreht text.setOri(rotation) den Text auf den Winkel rotation. Jetzt wird der Text-Stimulus gezeichnet und mit win.flip() angezeigt. Sobald die Leertaste gedrückt wird, endet die Schleife, und die letzten beiden Zeilen des Scripts werden ausgeführt.

Tipp

Die Schreibweise x += 1 erhöht den Wert von x um 1. Man könnte auch x = x + 1 schreiben.

win.flip() wartet üblicherweise auf die nächste Bildschirm-Aktualisierung. Bei einem Bildschirm mit 60 Hz kann die Schleife daher höchstens ungefähr 60 Mal pro Sekunde durchlaufen werden. Benötigt der Code innerhalb der Schleife zu viel Zeit, werden einzelne Aktualisierungen ausgelassen.

Animierte Stimuli

Im vorigen Beispiel haben wir gesehen, wie wir die Orientierung eines Text-Stimulus mit text.setOri(rotation) in einer Schleife kontinuierlich verändern können. Dasselbe Prinzip können wir auf beliebige visuelle Stimuli übertragen, um diese zu animieren.

Das folgende Beispiel zeigt, wie man einen Kreis bewegt und gleichzeitig dessen Farbe ändert (siehe dazu die PsychoPy-Hilfe über Farben).

from psychopy import core, visual
from psychopy.hardware import keyboard

win = visual.Window(size=[800, 800])
kb = keyboard.Keyboard()

pos = [0, 0]  # anfängliche x- und y-Position
speed = [0.03, -0.02]  # anfängliche x- und y-Geschwindigkeit
colors = ["red", "yellow", "green"]
color = 0
circle = visual.Circle(win, radius=0.1, fillColor=colors[0], lineColor=None)

while True:
    keys = kb.getKeys(keyList=["escape"])
    if keys:
        break
    pos[0] += speed[0]
    pos[1] += speed[1]
    if pos[0] < -1 or pos[0] > 1:  # x-Position am Bildschirmrand?
        speed[0] = -speed[0]  # x-Richtung umkehren
        color = (color + 1) % 3  # nächste Farbe setzen
    if pos[1] < -1 or pos[1] > 1:  # y-Position am Bildschirmrand?
        speed[1] = -speed[1]  # y-Richtung umkehren
        color = (color + 1) % 3  # nächste Farbe setzen
    circle.setPos(pos)
    circle.setFillColor(colors[color])
    circle.draw()
    win.flip()

win.close()
core.quit()

Timer

In den meisten Experimenten ist es wichtig, Stimuli zu definierten Zeitpunkten anzuzeigen. Wir haben bereits eine Möglichkeit kennengelernt, eine bestimmte Zeit zu warten: core.wait(2) hält die Ausführung für ungefähr zwei Sekunden an. Während dieser Wartezeit kann das Script keine eigenen Anweisungen ausführen.

Im Gegensatz dazu blockieren sogenannte Timer den Programmablauf nicht. Generell gibt es in PsychoPy zwei verschiedene Arten an Timern:

  1. core.Clock misst die seit der Erstellung oder dem letzten Zurücksetzen vergangene Zeit in Sekunden und zählt hinauf.
  2. core.CountdownTimer misst die noch übrige Zeit in Sekunden und zählt hinunter.

Einen Timer der ersten Art erstellt man mit clock = core.Clock(). Damit beginnt der Timer bei Sekunde 0 zu laufen. Mit clock.getTime() erhalten wir die seit der Erstellung vergangenen Sekunden.

Beim Erstellen eines Countdown-Timers kann man die Startzeit in Sekunden angeben, von der heruntergezählt werden soll. timer = core.CountdownTimer(10) zählt beispielsweise von 10 Sekunden herunter. Der Wert kann negativ werden, wenn mehr als 10 Sekunden vergangen sind. Die aktuell noch übrige Zeit erhalten wir ebenfalls mit timer.getTime().

Man kann in einem Script beliebig viele Timer erstellen und sie zurücksetzen. clock.reset() setzt einen core.Clock auf 0 zurück. timer.reset() setzt einen core.CountdownTimer auf seine zuletzt verwendete Startzeit zurück, im obigen Beispiel also auf 10 Sekunden. Mit timer.reset(5) kann die neue Startzeit auch direkt auf 5 Sekunden gesetzt werden.

Das folgende Beispiel zeigt zwei Countdown-Timer. Die while-Schleifen laufen, solange die jeweilige verbleibende Zeit positiv ist. Damit werden die Zahlen für ungefähr drei beziehungsweise fünf Sekunden angezeigt.

from psychopy import core, visual

win = visual.Window(size=[800, 800])

text1 = visual.TextStim(win, text="", color="blue")
text2 = visual.TextStim(win, text="", color="red")

timer1 = core.CountdownTimer(3)
timer2 = core.CountdownTimer(5)

timer1.reset()
while timer1.getTime() > 0:
    text1.setText("{:.2f}".format(timer1.getTime()))
    text1.draw()
    win.flip()
timer2.reset()
while timer2.getTime() > 0:
    text2.setText("{:.2f}".format(timer2.getTime()))
    text2.draw()
    win.flip()

win.close()
core.quit()

Stroop als Script

Dies führt uns zum Schluss wieder zum Stroop-Experiment, das wir nun mit wenigen Zeilen selbst schreiben können. Es fehlt zwar die Speicherung von Daten wie Reaktionszeiten und Antwortgenauigkeit; diese würde jedoch nur einige zusätzliche Zeilen erfordern. Im Vergleich mit dem automatisch generierten Code ist die selbst erstellte Variante wesentlich übersichtlicher und dadurch einfacher zu verstehen.

from psychopy import core, data, visual
from psychopy.hardware import keyboard


win = visual.Window(fullscr=True)  # Vollbildmodus
kb = keyboard.Keyboard()

s = """Simple Stroop

Name the color of the word on the screen.
Do not read the word!

If the word is red, press 'r'.
If the word is blue, press 'b'.
If the word is green, press 'g'.

Press Space when you are ready.
"""
text = visual.TextStim(win=win, text=s, color="white", height=0.05)
text.draw()
win.flip()
kb.waitKeys(keyList=["space"])

conditions = data.importConditions("conditions.xlsx")
trials = data.TrialHandler(trialList=conditions, nReps=5, method="random")
timer = core.CountdownTimer()
text.setHeight(0.1)

for trial in trials:
    timer.reset(2)
    text.setText(trial["word"])
    text.setColor(trial["color"])
    kb.clearEvents()
    kb.clock.reset()
    while timer.getTime() > 0:
        if timer.getTime() > 1:
            text.draw()
        win.flip()
        keys = kb.getKeys(keyList=["r", "g", "b", "escape"])
        if keys:
            if keys[0].name == "escape":
                core.quit()
            break

win.close()
core.quit()

Neu an diesem Script ist die Möglichkeit, mit data.TrialHandler die Bedingungen aus der Datei conditions.xlsx zu Trials zusammenzustellen. Über das Ergebnis kann dann iteriert werden; jede Iteration entspricht einem Trial. Durch method="random" werden die Bedingungen bei jeder Wiederholung neu gemischt.

Übungen

Übung 1

Erzeugen Sie das folgende PsychoPy-Experiment direkt als Script, also mit PsychoPy Coder:

Im Experiment sollen drei verschiedene visuelle Stimuli, z.B. Kreis, Polygon, Text oder Bild, gleichzeitig animiert werden. Innerhalb einer Schleife, die bis zum Drücken der Escape-Taste läuft, soll sich bei jedem der drei Stimuli zumindest eine Eigenschaft wie Position, Größe, Farbe oder Orientierung kontinuierlich verändern. Alle drei Stimuli sollen in derselben Schleifeniteration aktualisiert werden.
