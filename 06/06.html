6 – Listen, Tupel und Dictionaries

Einführung in Python und PsychoPy

Autor

Clemens Brunner

Veröffentlicht

5. November 2026

Datentypen im Überblick

Die grundlegenden Datentypen in Python können grob in folgende Kategorien unterteilt werden:

  • Logischer Datentyp (bool)
  • Numerische Datentypen (int, float, complex)
  • Sammlungstypen (str, list, tuple, dict)

Den logischen und die numerischen Datentypen sind wir bereits begegnet. In dieser Einheit lernen wir die Sammlungstypen list, tuple und dict kennen, mit denen man mehrere Objekte in einem einzigen Objekt zusammenfasst. Strings (str) behandeln wir dann in der nächsten Einheit im Detail.

Eine wichtige Eigenschaft vieler Datentypen ist, ob ihre Objekte mutable (veränderbar) oder immutable (nicht veränderbar) sind. Erstere können auch nach ihrer Erstellung verändert werden, letztere hingegen nicht.

  • Mutable (veränderbar): list, dict
  • Immutable (nicht veränderbar): int, float, complex, str, tuple

Listen erstellen

Wir widmen uns nun dem Sammlungstyp list. Listen zählen zu den wichtigsten Datentypen in Python und eignen sich hervorragend, um mehrere zusammengehörige Werte zu speichern. Viele Konzepte, die wir anhand von Listen kennenlernen, lassen sich später auch auf andere Sammlungstypen übertragen.

Eine Liste (list) gehört auch zu den Sequenzdatentypen. Sequenzen sind Sammlungstypen, deren Elemente in einer festen Reihenfolge gespeichert werden. Im Gegensatz zu anderen Sequenzdatentypen können Listen Elemente mit unterschiedlichen und beliebigen Datentypen enthalten, zum Beispiel Zahlen, Wahrheitswerte oder sogar weitere Listen. Eine Liste erstellt man mit eckigen Klammern, innerhalb derer die einzelnen Elemente durch Kommas getrennt angegeben werden:

x = [23, "Hallo", "test", 1.44, True]
y = [1, "1", [1, 2, 3], ["test", False, [True, True, 2, 4]]]

Indizieren und Slicen

Auf einzelne Elemente einer Liste greift man durch Indizieren zu. Den Index (also die Position des gewünschten Elements) gibt man dabei nach dem Objekt in eckigen Klammern an.

Wichtig

Python beginnt mit 0 zu zählen, d.h. das erste Element hat den Index 0. Den Index kann man daher als Unterschied/Abstand zum ersten Element interpretieren.

x[0]  # erstes Element
23
x[1]  # zweites Element
'Hallo'

Mit negativen Indizes kann man Elemente von hinten nach vorne ansprechen, d.h. −1 ist das letzte Element, −2 das vorletzte, usw.

x[-1]  # letztes Element
True
x[-2]  # vorletztes Element
1.44

Man kann auch mehrere Elemente auf einmal herausgreifen. Dazu schreibt man in die eckigen Klammern den Startindex, einen Doppelpunkt, und den Endindex. Wenn man auf diese Art (also unter Verwendung des Doppelpunkts) mehrere Elemente herausgreift, spricht man von einem Slice.

Wichtig

Der Endindex zählt nicht mehr zum Bereich dazu!

x[1:4]  # 3 Elemente, Index 1, 2, 3
['Hallo', 'test', 1.44]

Gibt man den ersten Index nicht an, wird vom ersten Element (inklusive) gezählt. Gibt man den Endindex nicht an, wird bis zum letzten Element (inklusive) gezählt.

x[:2]  # die ersten 2 Elemente
[23, 'Hallo']
x[2:]  # ab Index 2 bis zum letzten Element
['test', 1.44, True]
Tipp

Die Tatsache, dass der Startindex immer inklusive und der Endindex immer exklusive ist, hat den Vorteil, dass man sich durch die Differenz der beiden Indizes sofort die Anzahl der Elemente im Slice ausrechnen kann. Beispielsweise erkennt man so, dass x[73:81] genau \(81 - 73 = 8\) Elemente enthält.

Man kann optional nach dem Endindex noch einen weiteren Doppelpunkt gefolgt von der Schrittweite angeben (standardmäßig ist diese Schrittweite 1). So kann man z.B. jedes zweite Element herausgreifen:

x[::2]
[23, 'test', True]

Wenn man die Reihenfolge der Elemente umdrehen möchte, gibt man als Schrittweite −1 an:

x[::-1]  # Liste in umgekehrter Reihenfolge
[True, 1.44, 'test', 'Hallo', 23]

Indizieren und Slicen funktionieren bei allen Sequenzdatentypen auf dieselbe Art und Weise – also auch bei Strings, die wir in der nächsten Einheit behandeln werden.

Arbeiten mit Listen

Methoden

Für Listen gibt es in Python viele praktische spezielle Funktionen. Diese werden direkt auf ein Listen-Objekt angewandt:

x.append(13)

Zuerst gibt man das Objekt an (im Beispiel die Liste x), gefolgt von einem Punkt, gefolgt vom Namen der Funktion (im Beispiel append), die man aufrufen möchte. Eine solche Funktion nennt man Methode, da sie direkt auf ein zuvor spezifiziertes Objekt angewendet wird. Diese Schreibweise hat den Vorteil, dass sofort klar wird, dass die Methode zum Objekt gehört.

Tipp

Welche Methoden verfügbar sind, hängt vom Datentyp des Objekts ab. Im interaktiven Interpreter kann man sich die Methoden eines Objekts anzeigen lassen, indem man seinen Namen, gefolgt von einem Punkt, eingibt und dann die Tabulator-Taste drückt. Alternativ listet die Funktion dir alle möglichen Methoden eines Objekts auf:

dir(x)

Bevor wir uns später einige wichtige Listenmethoden genauer ansehen, betrachten wir zunächst eine allgemeine Funktion, mit der sich die Anzahl der Elemente einer Liste bestimmen lässt.

Länge

Die Funktion len gibt die Länge der Liste (also die Anzahl der Elemente in der Liste) zurück. Sehen wir uns noch einmal die beiden oben definierten Listen x und y an:

x
[23, 'Hallo', 'test', 1.44, True, 13]
y
[1, '1', [1, 2, 3], ['test', False, [True, True, 2, 4]]]

Diese enthalten 5 bzw. 4 Elemente:

len(x)
6
len(y)
4

In der Liste y sind das dritte und vierte Element selbst wieder Listen:

y[2]
[1, 2, 3]
y[3]
['test', False, [True, True, 2, 4]]

Letztere enthält eine weitere Liste am Ende (mit Index 2):

y[3][2]
[True, True, 2, 4]

Eine leere Liste ist eine ganz normale Liste, nur eben mit keinen Elementen (also mit einer Länge 0):

z = []
len(z)
0
type(z)
list

Elemente verändern

Nachdem Listen mutable sind, kann man einzelne Elemente auch nach der Erstellung der Liste ändern (neu zuweisen).

x
[23, 'Hallo', 'test', 1.44, True, 13]
x[1] = 111111
x
[23, 111111, 'test', 1.44, True, 13]
x[0] = None
x
[None, 111111, 'test', 1.44, True, 13]

Operatoren + und *

Zwei oder mehr Listen kann man mit dem +-Operator zu einer neuen Liste verbinden:

[1, 2, "drei"] + ["vier", 5, 6.0]
[1, 2, 'drei', 'vier', 5, 6.0]

Der *-Operator vervielfältigt eine Liste:

[1, 2.0, "drei"] * 3
[1, 2.0, 'drei', 1, 2.0, 'drei', 1, 2.0, 'drei']

Elemente zu Listen hinzufügen

Mit der bereits im einführenden Beispiel erwähnten Methode append kann man neue Elemente am Ende einer Liste hinzufügen.

x
[None, 111111, 'test', 1.44, True, 13]
x.append(13)
x
[None, 111111, 'test', 1.44, True, 13, 13]

Weil Listen mutable sind, wird hier die Liste direkt verändert; eine erneute Zuweisung zu einem Namen ist nicht notwendig bzw. führt nicht zum gewünschten Ergebnis, was im folgenden Beispiel ersichtlich ist:

a = x.append(25)
print(a)  # Listen-Methoden geben nichts (None) zurück, da Sie die Liste direkt ändern
None
x  # geänderte Liste
[None, 111111, 'test', 1.44, True, 13, 13, 25]
Wichtig

Listen-Methoden verändern die Liste direkt (in-place) und geben nichts (None) zurück.

Möchte man gleich mehrere Elemente hinzufügen, kann man die Methode extend benutzen:

x.extend([99, "HH", "zz"])
x
[None, 111111, 'test', 1.44, True, 13, 13, 25, 99, 'HH', 'zz']
Tipp

Versuchen Sie anhand der folgenden zwei Befehle den Unterschied zwischen append und extend zu erklären:

x.extend([99, "HH", "zz"])
x.append([99, "HH", "zz"])

Elemente aus Listen entfernen

Um bestimmte Elemente aus der Liste zu entfernen, verwendet man den del-Befehl.

x = ["A", "b", 3, 4, "fünf"]
del x[1]  # löscht das Element mit dem Index 1
x
['A', 3, 4, 'fünf']
Hinweis

Beachten Sie, dass del ein Python-Keyword ist und keine Funktion. Daher handelt es sich bei del x[1] auch nicht um einen Funktionsaufruf, Klammern als Aufrufoperator sind also nicht notwendig!

Alternativ kann man auch die Methode pop zum Löschen eines Elementes an einem bestimmten Index verwenden. Diese gibt das entfernte Element auch zurück (was del nicht tut).

x = ["A", "b", 3, 4, "fünf"]
x.pop(1)
'b'
x
['A', 3, 4, 'fünf']

Die Methode remove entfernt das erste Element aus der Liste, welches dem gesuchten Wert entspricht. Hier gibt man also nicht den zu entfernenden Index an, sondern den zu löschenden Wert.

x = ["A", "b", 31, 41, "fünf"]
x.remove(31)
x
['A', 'b', 41, 'fünf']

Listen sortieren

Wenn eine Liste sortierbare Elemente enthält (z.B. lauter Zahlen), kann man sie mit der Methode sort sortieren.

h = [6, 9, 23, 1, -78, 44]
h.sort()
h
[-78, 1, 6, 9, 23, 44]
Tipp

Was passiert, wenn man eine Liste mit nicht sortierbaren Elementen sortieren möchte (z.B. die Liste x aus dem vorigen Beispiel)?

Listen umkehren

Eine Liste kann man mit folgendem Slice umkehren (die ursprüngliche Liste ändert sich dabei aber nicht):

h[::-1]
[44, 23, 9, 6, 1, -78]
h
[-78, 1, 6, 9, 23, 44]

Es gibt aber noch eine zweite Möglichkeit mit der Methode reverse, welche die Liste direkt (in-place) verändert:

h.reverse()
h
[44, 23, 9, 6, 1, -78]

Listen iterieren

Mit dem in-Operator kann man überprüfen, ob ein bestimmtes Element in einer Liste enthalten ist.

2 in h
False
-78 in h
True

Eine Liste ist wie jeder Sequenzdatentyp iterierbar, d.h. man kann mit einer for-Schleife über die einzelnen Elemente iterieren:

for k in [2, "fünf", 3.14, "sieben"]:
    print(k)
2
fünf
3.14
sieben

Die Schleifenvariable k nimmt in jeder Iteration die einzelnen Werte der Liste an.

Tupel

Tupel (englische Schreibweise Tuple) verhalten sich wie Listen, sind aber immutable. Das kann sinnvoll sein, wenn man sicherstellen möchte, dass die Daten in einem Tupel nicht versehentlich geändert werden.

Tupel erstellt man wie Listen, nur lässt man die eckigen Klammern weg (man benötigt auch keine runden Klammern, obwohl diese manchmal in Kombination mit anderen Befehlen syntaktisch notwendig sind, z.B. wenn man ein Tupel als Argument übergeben möchte).

t = "A", "b", 3, 4, "fünf"
t
('A', 'b', 3, 4, 'fünf')
t[1]
'b'
t[1] = "c"  # Fehler!
---------------------------------------------------------------------------
TypeError                                 Traceback (most recent call last)
Cell In[46], line 1
----> 1 t[1] = "c"  # Fehler!

TypeError: 'tuple' object does not support item assignment
Tipp

Ein Tupel mit einem Element erstellt man mit einem nachgestellten Komma:

t = "A",
t
('A',)

Die Klammern sind, wie bereits erwähnt, optional:

t = ("A",)
t
('A',)

List Comprehensions

List Comprehensions sind eine alternative Möglichkeit zur Erstellung von Listen. List Comprehensions sind im Prinzip Schleifen, die aber syntaktisch wesentlich kompakter (kürzer) sind.

Nehmen wir als Beispiel eine Liste der Quadratzahlen von 0 bis 9. Mit einer normalen Schleife würde man diese Liste so erzeugen:

squares = []  # wir beginnen mit einer leeren Liste
for x in range(10):
    squares.append(x**2)  # Liste wird befüllt

squares
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
Hinweis

Ein gängiges Muster zur Erstellung einer Liste besteht darin, mit einer leeren Liste zu beginnen und ihr dann in einer Schleife die einzelnen Elemente hinzuzufügen.

Mit einer List Comprehension kann man das wesentlich kompakter schreiben:

squares = [x**2 for x in range(10)]
squares
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

Die Zutaten einer List Comprehension sind:

  • Zwei umschließende eckige Klammern (die ja eine Liste definieren)
  • Ein Ausdruck (x**2 im Beispiel)
  • Eine for-Anweisung (for x in range(10) im Beispiel)
  • Optional eine if-Bedingung

Weitere Beispiele veranschaulichen, dass List Comprehensions eine Operation auf alle Elemente einer Liste anwenden oder bestimmte Elemente herausfiltern können:

vec = [-4, -2, 0, 2, 4]
[x * 2 for x in vec]  # neue Liste mit verdoppelten Einträgen
[-8, -4, 0, 4, 8]
[x for x in vec if x >= 0]  # negative Einträge herausfiltern
[0, 2, 4]
[abs(x) for x in vec]  # eine Funktion auf alle Elemente separat anwenden
[4, 2, 0, 2, 4]
Hinweis

In Python ist es mit Listen also nicht einfach möglich, elementweise Berechnungen durchzuführen.

x = [4, -3, 7, 81, 11]
x * 2
[4, -3, 7, 81, 11, 4, -3, 7, 81, 11]

So werden die einzelnen Elemente nicht mit 2 multipliziert, sondern die Liste wird “verdoppelt”. Immer dann, wenn man eine Operation elementweise anwenden möchte, muss man daher eine List Comprehension (oder die entsprechende Schleife) verwenden.

Für numerische Anwendungen ist das aber denkbar unpraktisch. Wir werden in einer der folgenden Einheiten lernen, wie man Python dennoch für numerische Berechnungen verwenden kann (nämlich dank eines neuen Datentyps namens NumPy Array, welches vom Zusatzpaket NumPy zur Verfügung gestellt wird).

In der Praxis verwendet man List Comprehensions, solange sie einfach und übersichtlich bleiben. Bei mehreren geschachtelten Schleifen oder Bedingungen sind explizite Schleifen meist besser lesbar. List Comprehensions sind nicht zwingend notwendig, sondern eine kompakte Schreibweise für bestimmte Muster. Solche Sprachkonstrukte bezeichnet man als syntactic sugar: sie machen Code kürzer und oft leichter lesbar, ohne die Möglichkeiten der Sprache zu erweitern.

Dictionaries

Dictionaries (dict) sind Sammlungstypen, die Werte (Values) jeweils einem Schlüssel (Key) zuordnen. Man kann sie sich wie ein Sprachwörterbuch vorstellen: Um die Übersetzung eines Wortes zu finden, schlägt man das Wort als Schlüssel nach und erhält den zugehörigen Wert. In Python erstellt man ein Dictionary mit geschwungenen Klammern. Die einzelnen Key-Value-Paare werden, wie die Elemente einer Liste, durch Kommas getrennt; Key und Value trennt ein Doppelpunkt.

Folgendes Beispiel zeigt ein dict mit drei Einträgen:

d = {"Haus": "house", "Schlange": "snake", "Katze": "cat"}

Alternativ kann man die Funktion dict verwenden und das Dictionary mit Keyword-Argumenten erstellen:

d = dict(Haus="house", Schlange="snake", Katze="cat")
Hinweis

Die Namen der Keyword-Argumente werden ohne Anführungszeichen geschrieben. Python verwendet sie dabei als Strings und somit als Keys im Dictionary.

Auf einen einzelnen Value greift man wieder mit eckigen Klammern zu. Anders als bei Listen verwendet man dabei keinen numerischen Index, sondern den jeweiligen Key:

d["Haus"]
'house'
d["Schlange"]
'snake'
Wichtig

Bei Dictionaries erfolgt der Zugriff über Keys, nicht über die Position eines Elements. Daher spricht man bei Dictionaries nicht vom ersten, zweiten oder dritten Eintrag, bei Listen hingegen schon.

Wie Listen können Dictionaries Werte unterschiedlicher Datentypen enthalten. Als Keys eignen sich beispielsweise Strings, Zahlen und Tupel; Listen können nicht als Keys verwendet werden. Neue Einträge fügt man hinzu, indem man einem neuen Key einen Value zuweist.

d
{'Haus': 'house', 'Schlange': 'snake', 'Katze': 'cat'}
d[23] = "tt"  # Key 23, Value "tt"
d[1] = 3.14  # Key 1, Value 3.14
d["L"] = [1, 2, 3]  # Key "L", Value [1, 2, 3]
d
{'Haus': 'house',
 'Schlange': 'snake',
 'Katze': 'cat',
 23: 'tt',
 1: 3.14,
 'L': [1, 2, 3]}

Möchte man auf einen Eintrag mit einem Key zugreifen, der im Wörterbuch nicht existiert, erhält man eine Fehlermeldung.

d[0]  # Fehler!
---------------------------------------------------------------------------
KeyError                                  Traceback (most recent call last)
Cell In[62], line 1
----> 1 d[0]  # Fehler!

KeyError: 0

Arbeiten mit Dictionaries

Die Länge eines Dictionaries, also die Anzahl der Einträge, bestimmt man mit der Funktion len:

len(d)
6

Mit den Methoden keys und values kann man sich alle Keys beziehungsweise Values eines Dictionaries ausgeben lassen:

d.keys()
dict_keys(['Haus', 'Schlange', 'Katze', 23, 1, 'L'])
d.values()
dict_values(['house', 'snake', 'cat', 'tt', 3.14, [1, 2, 3]])

Ob ein Wert als Key vorkommt, kann man mit in überprüfen:

"Katze" in d
True
"cat" in d
False

Wenn man wissen möchte, ob ein Wert als Value vorkommt, verwendet man die values-Methode:

"cat" in d.values()
True

Selbstverständlich kann man über ein Dictionary auch iterieren – in diesem Fall wird über die Keys iteriert:

for k in d:
    print(k)
Haus
Schlange
Katze
23
1
L

Auf die entsprechenden Values greift man dann durch Indizieren zu:

for k in d:
    print(k, ":", d[k])
Haus : house
Schlange : snake
Katze : cat
23 : tt
1 : 3.14
L : [1, 2, 3]

Die Methode items gibt alle Key-Value-Paare als Tupel zurück:

d.items()
dict_items([('Haus', 'house'), ('Schlange', 'snake'), ('Katze', 'cat'), (23, 'tt'), (1, 3.14), ('L', [1, 2, 3])])

Damit kann man in einer Schleife sowohl auf die Keys als auch auf die Values direkt zugreifen:

for k, v in d.items():
    print(k, ":", v)
Haus : house
Schlange : snake
Katze : cat
23 : tt
1 : 3.14
L : [1, 2, 3]

Die gleichzeitige Zuweisung an die Namen k und v bezeichnet man in Python als Unpacking. Da d.items() in jeder Iteration ein Tupel mit Key und Value liefert, kann man dessen beiden Elementen direkt zwei Namen zuweisen.

Tipp

Ein weiteres Beispiel für Unpacking ist das Vertauschen von zwei Werten. Zunächst kann man damit zwei (oder mehr) Namen gleichzeitig zuweisen:

a, b = 15, 23
a
15
b
23

Da Python immer zuerst die rechte Seite einer Zuweisung auswertet, kann man mit diesem Muster auch zwei Werte vertauschen:

a, b = b, a
a
23
b
15

Möchte man den Fehler beim Zugriff auf einen nicht existierenden Key vermeiden, kann man stattdessen die Methode get verwenden. Diese Methode hat zwei Parameter, nämlich einen Key und einen Standardwert, der zurückgegeben wird, falls der angegebene Key im Dictionary nicht existiert:

d
{'Haus': 'house',
 'Schlange': 'snake',
 'Katze': 'cat',
 23: 'tt',
 1: 3.14,
 'L': [1, 2, 3]}
d["psy"]  # Fehler, Key "psy" existiert nicht
---------------------------------------------------------------------------
KeyError                                  Traceback (most recent call last)
Cell In[80], line 1
----> 1 d["psy"]  # Fehler, Key "psy" existiert nicht

KeyError: 'psy'
d.get("psy", 0)  # Key "psy" existiert nicht, also wird 0 zurückgegeben
0
d.get("Schlange", "Tier")  # Key "Schlange" existiert
'snake'
d.get("snake", "Schlange")  # Key "snake" existiert nicht
'Schlange'
Tipp

Gibt man für get keinen Standardwert an, wird None zurückgegeben, falls der Key nicht existiert:

d.get("psy")

Zu beachten ist, dass in den Fällen, wo Standardwerte zurückgegeben werden, diese Einträge nicht automatisch zum Dictionary hinzugefügt werden:

d
{'Haus': 'house',
 'Schlange': 'snake',
 'Katze': 'cat',
 23: 'tt',
 1: 3.14,
 'L': [1, 2, 3]}
d.get("X", 42)  # Key "X" existiert nicht
42
d  # Key "X" existiert immer noch nicht
{'Haus': 'house',
 'Schlange': 'snake',
 'Katze': 'cat',
 23: 'tt',
 1: 3.14,
 'L': [1, 2, 3]}

Möchte man diese neuen Einträge gleich dem Dictionary hinzufügen, verwendet man die Methode setdefault:

d.setdefault("X", 42)  # Key "X" existiert nicht
42
d  # jetzt gibt es den Key "X"
{'Haus': 'house',
 'Schlange': 'snake',
 'Katze': 'cat',
 23: 'tt',
 1: 3.14,
 'L': [1, 2, 3],
 'X': 42}
d.setdefault("X", 100)  # Key "X" existiert bereits
42
d
{'Haus': 'house',
 'Schlange': 'snake',
 'Katze': 'cat',
 23: 'tt',
 1: 3.14,
 'L': [1, 2, 3],
 'X': 42}
