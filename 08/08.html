Einführung in Python und PsychoPy

Autor

Clemens Brunner

Veröffentlicht

Standardbibliothek und Zusatzpakete

Eine Python-Installation besteht aus der Programmiersprache Python, einem Interpreter (der Python-Code ausführt) und der umfangreichen Standardbibliothek. Python selbst stellt nur grundlegende Programmierkonstrukte zur Verfügung (z.B. Schleifen, Bedingungen und einige eingebaute Funktionen). Die mitgelieferte Standardbibliothek erweitert diese Kernfunktionalität um zusätzliche Datentypen, Ein-/Ausgabe, mathematische Funktionen und vieles mehr. Auf die einzelnen Module der Standardbibliothek greift man mit import zu – so haben wir z.B. bereits import math verwendet, um math.sqrt oder math.pi benutzen zu können.

Zusätzlich gibt es hunderttausende sogenannte Python-Pakete, die sehr einfach zu einer existierenden Python-Installation hinzugefügt werden können. Diese Pakete sind komplett unabhängig von Python, werden also auch nicht von denselben Personen entwickelt und veröffentlicht. Der Python Package Index (PyPI) sammelt alle verfügbaren Pakete an einer zentralen Stelle. Das offizielle Werkzeug, um Pakete aus dem PyPI zu installieren, nennt sich pip und wird automatisch mit der offiziellen Python-Installation mitgeliefert.

In dieser Einheit lernen wir, wie man mit pip Zusatzpakete verwaltet und wie man installierte Pakete mit import in eigenen Programmen verwendet. Dieses Wissen benötigen wir in den folgenden Einheiten, in denen wir die Zusatzpakete NumPy, Matplotlib und PsychoPy verwenden werden.

Pakete mit pip verwalten

Das Werkzeug pip kann neue Pakete installieren, bereits installierte Pakete aktualisieren oder auch komplett wieder entfernen. Eine Python-Installation sollte damit regelmäßig gewartet werden, d.h. veraltete Pakete sollten nach Möglichkeit aktualisiert werden. Die Standardbibliothek wird dadurch allerdings nicht beeinflusst – diese ändert sich nur, wenn man eine neuere Python-Version installiert.

Dabei ist pip ein sogenanntes Kommandozeilenprogramm, d.h. es verfügt über keine grafische Oberfläche, sondern wird im Terminal ausgeführt. Um die folgenden Beispiele nachzuvollziehen, muss man also zuerst ein Terminal öffnen.

Wichtig

Das Terminal ist ein Programm bzw. Fenster, in dem man Textbefehle eingibt. Darin läuft eine sogenannte Shell, die Betriebssystem-Befehle ausführen kann.

Davon zu unterscheiden ist der Python-Interpreter: er führt Python-Code wie import math aus. Die folgenden pip-Befehle gehören daher ins Terminal bzw. in die Shell und nicht in die IDLE-Shell, in der der Python-Interpreter läuft!

Wir rufen pip immer über den Python-Interpreter mit der Option -m auf (mehr dazu weiter unten). Um zu testen, ob pip funktioniert und welche Version installiert ist, gibt man Folgendes ein:

  • Windows
  • macOS/Linux
py -m pip --version
python3 -m pip --version

Wenn man hier eine Versionsnummer angezeigt bekommt (z.B. 25.2), funktioniert pip korrekt. Falls hier eine Fehlermeldung ausgegeben wird, wurde vermutlich die Python-Installation nicht korrekt durchgeführt. In diesem Fall installiert man am besten anhand der in der ersten Einheit beschriebenen Schritte Python erneut.

Hinweis

In allen folgenden Beispielen verwenden wir unter Windows py, unter macOS und Linux hingegen python3. Ersetzen Sie py -m pip also je nach Betriebssystem durch python3 -m pip.

Wenn man wissen möchte, welche Pakete installiert sind, verwendet man den folgenden Befehl:

py -m pip list

Die Ausgabe beinhaltet alle installierten Pakete, einschließlich ihrer Namen und Versionen. Wenn man Python gerade erst frisch installiert hat, enthält diese Liste nur wenige Einträge.

Bevor man ein neues Paket installieren kann, muss man dessen Namen kennen. Die PyPI-Website kann verwendet werden, um nach einem bestimmten Paket zu suchen. Ein Paket kann dann wie folgt installiert werden (<package-name> muss durch den tatsächlichen Namen ersetzt werden):

py -m pip install <package-name>
Hinweis

Der Name hinter pip install ist ein vorgegebener Projektname auf PyPI und kein selbstgewählter Name in einem Python-Programm. Daher muss er nicht den Regeln aus Kapitel 2 folgen: er kann beispielsweise Bindestriche enthalten. Außerdem kann er vom Namen abweichen, mit dem das Paket später importiert wird. So wird z.B. das Projekt scikit-learn mit py -m pip install scikit-learn installiert, aber im Python-Programm mit import sklearn verwendet.

Das Entfernen eines Pakets ist ähnlich einfach:

py -m pip uninstall <package_name>

Eine Liste aller Pakete, die aktualisiert werden können, erhält man mit:

py -m pip list --outdated

Falls dieser Befehl veraltete Pakete anzeigt, kann man jedes einzelne Paket mit folgendem Befehl aktualisieren:

py -m pip install --upgrade <package-name>
Tipp

Grundsätzlich könnte man pip auch direkt aufrufen (also einfach pip install ... bzw. pip3 install ...). Es kann aber vorkommen, dass mehrere Python-Versionen auf einem Computer installiert sind. Dann ist nicht immer eindeutig, zu welcher Python-Installation ein direkt aufgerufenes pip gehört – und man installiert das Paket womöglich in die “falsche” Python-Version.

Die Option -m weist den Python-Interpreter an, ein Modul als Programm auszuführen – in diesem Fall das Modul pip. Der große Vorteil: Man ruft pip immer über genau jenen Python-Interpreter auf, den man auch zum Ausführen von Programmen verwendet (py unter Windows bzw. python3 unter macOS/Linux). So installiert man ein Paket garantiert in die richtige Python-Installation. Aus diesem Grund verwenden wir in diesem Kurs durchgängig die Schreibweise py -m pip bzw. python3 -m pip.

Pakete verwenden: import

Ein installiertes Paket steht nicht automatisch in einem Programm zur Verfügung – man muss es zuerst mit import importieren (genau wie ein Modul aus der Standardbibliothek). Erst danach kann man auf die Funktionen und Objekte des Pakets zugreifen. Für den Zugriff verwendet man wieder die Punktschreibweise (Paketname, Punkt, Name des gewünschten Objekts).

Die einfachste Form importiert ein ganzes Modul bzw. Paket:

import math

math.sqrt(16)
4.0

Man kann auch nur einzelne Namen aus einem Modul importieren. Diese stehen dann direkt (ohne vorangestellten Modulnamen) zur Verfügung:

from math import sqrt, pi

sqrt(16)
4.0
pi
3.141592653589793

Schließlich kann man einem importierten Paket beim Import auch einen kürzeren Aliasnamen geben. Das ist bei Paketen mit langen Namen praktisch und bei manchen Paketen sogar üblich. So wird NumPy fast immer als np importiert:

import numpy as np

np.array([1, 2, 3])
array([1, 2, 3])
Hinweis

Der Alias ist frei wählbar, aber für viele bekannte Pakete gibt es etablierte Konventionen (z.B. import numpy as np oder import matplotlib.pyplot as plt). Halten Sie sich an diese Konventionen, damit Ihr Code für andere gut lesbar bleibt. Wir werden NumPy und Matplotlib in den nächsten beiden Einheiten kennenlernen.

Module und Pakete

Ein Modul ist eine einzelne Python-Datei mit der Endung .py. In einem Modul können Funktionen, Variablen und Klassen stehen, die man in anderen Programmen wiederverwenden möchte. Die Datei math.py wäre beispielsweise ein Modul mit dem Namen math.

Ein Paket ist dagegen ein Verzeichnis, das mehrere Module zusammenfasst. So kann zusammengehöriger Code übersichtlich organisiert werden. Ein Paket kann auch weitere Pakete enthalten; diese nennt man Unterpakete (englisch subpackages). Ein einfaches Paket könnte so aussehen:

my_package/
  __init__.py
  arithmetic.py
  text.py
  analysis/
    __init__.py
    statistics.py

Die Dateien arithmetic.py, text.py und statistics.py sind Module, my_package und analysis sind Pakete. Die Datei __init__.py markiert ein Verzeichnis üblicherweise als Paket; sie kann leer bleiben. Bei vielen modernen Paketen ist sie zwar nicht mehr zwingend erforderlich, für selbst geschriebene Pakete ist sie aber eine gute Konvention.

Punkte in einem Import beschreiben diese Struktur. Im folgenden Beispiel ist matplotlib ein Paket und pyplot ein darin enthaltenes Modul:

import matplotlib.pyplot as plt

Aus der oben gezeigten Struktur könnte man beispielsweise ein Modul aus einem Unterpaket importieren:

from my_package.analysis import statistics

Eigene Module schreiben

Um ein eigenes Modul zu schreiben, erstellt man einfach eine Python-Datei. Angenommen, im selben Verzeichnis befinden sich die beiden folgenden Dateien:

# greetings.py
def greeting(name):
    return f"Hallo, {name}!"
# main.py
import greetings

print(greetings.greeting("Mara"))

Wenn man main.py ausführt, findet Python die Datei greetings.py im selben Verzeichnis und importiert sie als Modul. Die Funktion wird mit greetings.greeting(...) aufgerufen. Dieses Beispiel zeigt auch, warum Modulnamen kurz, aussagekräftig und vollständig klein geschrieben werden sollten.

Auch bei eigenen Modulen kann man einzelne Namen direkt importieren oder einen Alias verwenden:

from greetings import greeting
import greetings as gr

print(greeting("Mara"))
print(gr.greeting("Jonas"))

Neue Pakete erkunden

Nach dem Import eines neuen Moduls oder Pakets kann die eingebaute Funktion dir einen ersten Überblick geben. Sie gibt eine Liste der Namen zurück, die darin verfügbar sind:

import math

dir(math)

Viele Einträge, die mit zwei Unterstrichen beginnen und enden (z.B. __name__), gehören zu den internen Eigenschaften eines Moduls. Für die tägliche Arbeit sind meist die übrigen Namen interessant. Um nur diese anzuzeigen, kann man sie mit einer List Comprehension filtern:

[name for name in dir(math) if not name.startswith("__")]

Bei einem neu installierten Paket funktioniert das genauso. Nach import numpy zeigt dir(numpy) beispielsweise die verfügbaren Funktionen, Klassen und Unterpakete. dir ersetzt keine Dokumentation, hilft aber beim ersten Erkunden eines unbekannten Pakets.

Code automatisch formatieren mit Ruff

Als konkretes Beispiel für ein nützliches Zusatzpaket sehen wir uns Ruff an. Damit kann man Python-Code automatisch überprüfen und formatieren lassen.

Das ist sinnvoll, weil es neben der Syntax, die man strikt einhalten muss, auch stilistische Konventionen gibt, die den Code lesbarer machen. Beispielsweise sind die folgenden drei Anweisungen alle syntaktisch korrekt und führen zum selben Ergebnis:

x = 1 + 2 + 3 * (16 - 7)
x=1+    2+  3*  (   16-7    )
x=1+2+3*(16-7)

Der erste Befehl ist aber am besten lesbar, weil alle Operatoren von jeweils einem Leerzeichen umgeben sind. Viele solche Empfehlungen sind im Python Enhancement Proposal 8 (PEP8) zusammengefasst. Ruff kann Code automatisch entsprechend formatieren.

Zunächst installiert man Ruff mit pip:

py -m pip install ruff

Danach kann man die folgenden Befehle im Terminal verwenden, um eine Datei namens test.py zu überprüfen und zu formatieren:

ruff check --fix test.py
ruff format test.py
Hinweis

Die beiden obigen Befehle sind Shell-Befehle und müssen, genau wie pip, im Terminal ausgeführt werden (nicht im Python-Interpreter). Damit sie funktionieren, muss sich die Datei test.py im aktuellen Verzeichnis befinden. Man kann den Befehl ls (bzw. dir unter Windows) verwenden, um den Inhalt des aktuellen Verzeichnisses anzuzeigen. Falls die Datei nicht aufscheint, kann man mit dem Befehl cd <Verzeichnis> in das entsprechende Verzeichnis wechseln.

Je nach Installation kann es außerdem sein, dass man ruff nicht direkt aufrufen kann. In diesem Fall sollte es mit py -m ruff (bzw. python3 -m ruff) anstelle von ruff funktionieren.
