5 – Funktionen II

Einführung in Python und PsychoPy

Autor

Clemens Brunner

Veröffentlicht

29. Oktober 2026

Allgemeines

In der vorigen Einheit haben wir gelernt, wie man Funktionen definiert, aufruft und mit return Werte zurückgibt. Nun vertiefen wir das Thema Funktionen: Wir sehen uns verschiedene Arten von Funktionsargumenten an – darunter Standard-, Schlüsselwort- und variable Argumente – und lernen außerdem, was es mit Gültigkeitsbereichen (Scopes) auf sich hat.

Argumente

Standard-Argumente

Eine Funktion kann ohne Parameter definiert werden oder eine bestimmte Anzahl an Parametern besitzen. Wenn eine bestimmte Anzahl an Parametern im Funktionskopf definiert wird, können einzelnen Parametern Standardwerte (sogenannte Standard- oder auch Default-Argumente) zugewiesen werden. Dies bedeutet, dass die Funktion auch mit weniger Argumenten aufgerufen werden kann, sofern für die entsprechenden Parameter Standardwerte definiert wurden.

def add(number, increment=1):  # increment hat den Standardwert 1
    return number + increment

Diese Funktion kann jetzt mit zwei Argumenten oder nur mit dem ersten Argument aufgerufen werden:

add(7, 1)
8
add(7)  # hier wird das Standard-Argument 1 für increment verwendet
8
add(7, 3)
10

Schlüsselwort-Argumente

Funktionen können auch so aufgerufen werden, dass die Namen der Parameter gemeinsam mit den Argumenten in der Form name=value explizit hingeschrieben werden. Man spricht dann von Schlüsselwort-Argumenten (englisch “Keyword Arguments”) (nicht zu verwechseln mit den Python-Schlüsselwörtern). D.h. die obige Funktion add kann auch so aufgerufen werden:

add(number=5)
6
add(number=5, increment=2)
7
add(increment=2, number=5)
7

Dies dient einerseits der besseren Lesbarkeit, da unmittelbar klar ist, welche Parameter welche konkreten Argumente erhalten. Werden alle Argumente als Schlüsselwort-Argumente angegeben, können sie in beliebiger Reihenfolge übergeben werden.

Wenn der Argumentname nicht angegeben wird, wird das Argument anhand seiner Position dem entsprechenden Parameter zugewiesen. Man spricht in diesem Fall von positionalen Argumenten. Man kann positionale und Schlüsselwort-Argumente beim Funktionsaufruf auch mischen, aber alle positionalen Argumente müssen vor dem ersten Schlüsselwort-Argument kommen.

add(5, increment=2)
7

Zur Veranschaulichung dient folgende Funktionsdefinition:

def test(name, number, exponent=5, offset=7, text="Hello"):
    print(text, name, end=" ")
    return number**exponent - offset

Die folgenden drei Funktionsaufrufe verwenden nur positionale Argumente:

test("Python", 2)
Hello Python 
25
test("Python", 3)
Hello Python 
236
test("Test", 3, 4)
Hello Test 
74

Schlüsselwort-Argumente sind besonders praktisch, wenn man für die meisten Parameter die Standardwerte verwenden möchte. Dann müssen nur jene Argumente angegeben werden, deren Wert vom Standardwert abweicht.

test("Test", 2, offset=2)
Hello Test 
30

Ohne Schlüsselwort-Argumente würde derselbe Aufruf nämlich wie folgt aussehen:

test("Test", 2, 5, 2)
Hello Test 
30

Man muss also in diesem Beispiel ein zusätzliches Argument 5 (für den Parameter exponent) übergeben, wenn man positionale Argumente verwendet, obwohl man ja ohnehin den Standardwert dieses Arguments verwendet.

Variable Argumente

Bisher haben wir nur Funktionen betrachtet, die eine feste Anzahl an Parametern besitzen. Manchmal ist es jedoch praktisch, wenn eine Funktion mit einer beliebigen Anzahl an Argumenten aufgerufen werden kann. Dazu wird bei der Funktionsdefinition vor den Parameternamen ein Stern (*) geschrieben.

def greet(*names):
    for name in names:
        print("Hallo", name)

Der Parameter names kann beliebig viele Argumente aufnehmen. Beim Aufruf der Funktion können daher unterschiedlich viele Namen übergeben werden:

greet("Anna")
Hallo Anna
greet("Anna", "Ben")
Hallo Anna
Hallo Ben
greet("Anna", "Ben", "Clara")
Hallo Anna
Hallo Ben
Hallo Clara

Alle übergebenen Argumente werden im Parameter names gesammelt und können anschließend beispielsweise mit einer for-Schleife verarbeitet werden. Wie Python diese Werte intern speichert, werden wir später im Kurs (in der Einheit über Listen und Tupel) noch genauer betrachten.

Variable Argumente können auch gemeinsam mit gewöhnlichen Parametern verwendet werden. Dabei müssen die gewöhnlichen Parameter immer vor dem Parameter mit * stehen.

def greet_all(greeting, *names):
    for name in names:
        print(greeting, name)

Hier wird das erste Argument dem Parameter greeting zugewiesen. Alle weiteren Argumente werden im Parameter names gesammelt.

greet_all("Hallo", "Anna", "Ben")
Hallo Anna
Hallo Ben
greet_all("Guten Morgen", "Anna", "Ben", "Clara")
Guten Morgen Anna
Guten Morgen Ben
Guten Morgen Clara
Hinweis

Der Parametername args ist in Python sehr verbreitet, aber nicht vorgeschrieben. Die folgende Funktionsdefinition ist daher gleichbedeutend mit der obigen:

def greet(*args):
    for name in args:
        print("Hallo", name)

Der Stern (*) ist entscheidend – der Name des Parameters kann frei gewählt werden.

Gültigkeitsbereiche

Jeder in Python definierte Name besitzt einen Gültigkeitsbereich (englisch Scope). Ein Name kann nur innerhalb seines Gültigkeitsbereichs verwendet werden.

Namen, die innerhalb einer Funktion definiert werden, sind nur innerhalb dieser Funktion sichtbar. Man spricht von einem lokalen Gültigkeitsbereich.

def test():
    s = 15  # s ist nur innerhalb der Funktion sichtbar
    print(s)

test()
15

Außerhalb der Funktion existiert dieser Name nicht:

print(s)
---------------------------------------------------------------------------
NameError                                 Traceback (most recent call last)
Cell In[24], line 1
----> 1 print(s)

NameError: name 's' is not defined

Umgekehrt kann eine Funktion auf Namen zugreifen, die außerhalb der Funktion definiert wurden:

s = 15  # globales s

def test():
    print(s)

test()
print(s)
15
15

Wird innerhalb der Funktion ein Name mit demselben Namen definiert, so ist innerhalb der Funktion nur noch dieser lokale Name sichtbar:

s = 15  # globales s

def test():
    s = 12  # lokales s
    print(s)

test()
print(s)
12
15

Das globale s bleibt dabei unverändert.

Ein häufiger Fehler entsteht, wenn man innerhalb einer Funktion auf einen Namen zugreifen möchte, bevor man ihn lokal definiert:

s = 15

def test():
    print(s)
    s = 12

test()
---------------------------------------------------------------------------
UnboundLocalError                         Traceback (most recent call last)
Cell In[27], line 7
      3 def test():
      4     print(s)
      5     s = 12
      6 
----> 7 test()

Cell In[27], line 4, in test()
      3 def test():
----> 4     print(s)
      5     s = 12

UnboundLocalError: cannot access local variable 's' where it is not associated with a value

Python erkennt bereits beim Einlesen der Funktion, dass s ein lokaler Name sein wird. Deshalb bezieht sich auch print(s) auf diesen lokalen Namen, obwohl er zu diesem Zeitpunkt noch keinen Wert besitzt.

Mit dem Schlüsselwort global kann stattdessen auf den globalen Namen zugegriffen werden:

s = 15

def test():
    global s
    print(s)
    s = 12

test()
print(s)
15
12

Dadurch wird das globale s geändert. In der Praxis sollte man global jedoch möglichst vermeiden. Stattdessen übergibt man benötigte Werte als Argumente an die Funktion und gibt Ergebnisse mit return zurück:

s = 15

def test(s):
    print(s)
    s = 12
    return s

print(s)
s = test(s)
print(s)
15
15
12
Tipp

Auch Parameter besitzen einen lokalen Gültigkeitsbereich. Sie verhalten sich wie Namen, die innerhalb der Funktion definiert wurden, und erhalten beim Funktionsaufruf ihre Werte von den übergebenen Argumenten.

Im letzten Beispiel heißen sowohl der globale Name als auch der Parameter s. Das ist jedoch Zufall – beide Namen sind unabhängig voneinander. Die Funktion könnte genauso gut mit einem anderen Namen oder direkt mit einem Wert aufgerufen werden:

x = 15
test(x)
15
12

Oder mithilfe eines Schlüsselwort-Arguments:

test(s=x)
15
12

Übungen

Übung 1

Schreiben Sie eine Funktion namens nonsense, welche drei Parameter namens a, b und c hat. Die beiden Argumente b und c sollen optional sein und die Standardwerte 10 bzw. 13 besitzen. Die Funktion soll a**2 - b * 2 + c**2 berechnen und zurückgeben (wir setzen voraus, dass man für a, b und c immer Zahlenwerte übergibt). Rufen Sie die Funktion dann mit folgenden Argumenten auf:

  1. Ohne Argumente
  2. Mit drei positionalen Argumenten
  3. Mit zwei positionalen Argumenten
  4. Mit einem Keyword-Argument
  5. Mit zwei Keyword-Argumenten
  6. Mit zwei positionalen Argumenten und einem Keyword-Argument
  7. Mit einem positionalem und einem Keyword-Argument

Wie sehen diese Funktionsaufrufe aus? Wie lauten die Rückgabewerte? Geben Sie für jeden Aufruf die Werte aller drei Argumente an!

Hinweis

Nur der erste Funktionsaufruf (ohne Argumente) verursacht einen Fehler, alle weiteren Aufrufe sind möglich!

Übung 2

Schreiben Sie eine Funktion namens maximum, welche eine beliebige Anzahl an Zahlen als Argumente erhält und die größte dieser Zahlen zurückgibt.

Beispiele:

maximum(7)  # gibt 7 zurück
maximum(7, 2, 9, 4)  # gibt 9 zurück

Verwenden Sie dafür weder die Funktion max() noch andere Hilfsfunktionen.

Hinweis

Für diese Aufgabe benötigen Sie den ersten übergebenen Wert als Startwert für das zu findende Maximum. Der Ausdruck numbers[0] liefert diesen ersten Wert (vorausgesetzt ist hier, dass der erste Parameter der Funktion numbers heißt). Wie dieser Ausdruck genau funktioniert, lernen wir in einer späteren Einheit kennen.

Übung 3

Schreiben Sie eine Funktion namens count_even, welche eine beliebige Anzahl an ganzen Zahlen erhält und zurückgibt, wie viele davon gerade sind.

Beispiele:

count_even(1, 2, 3, 4, 5, 6)  # gibt 3 zurück
count_even(1, 3, 5)  # gibt 0 zurück

Übung 4

Betrachten Sie das folgende Programm:

x = 5

def test(x):
    x = x + 2
    print(x)

test(x)
print(x)
  1. Welche Werte werden ausgegeben?
  2. Erklären Sie, warum sich der Wert von x außerhalb der Funktion nicht ändert.
  3. Ändern Sie das Programm so, dass die Variable x außerhalb der Funktion anschließend den Wert 7 besitzt, ohne das Schlüsselwort global zu verwenden.

Übung 5

Welche Ausgabe erzeugt das folgende Programm?

def show(a, b=2, c=3):
    print(a, b, c)

show(1)
show(1, 5)
show(1, c=7)
show(c=7, a=1)
show(1, 5, c=7)

Begründen Sie bei jedem Funktionsaufruf, welcher Parameter welchen Wert erhält.

Übung 6

Schreiben Sie eine Funktion namens power_sum, welche einen Parameter exponent und eine beliebige Anzahl weiterer Zahlen erhält. Die Funktion soll die Summe aller Zahlen berechnen, nachdem jede Zahl mit exponent potenziert wurde.

Beispiele:

power_sum(2, 1, 2, 3)

liefert den Rückgabewert 14, da \(1^2 + 2^2 + 3^2 = 14\).

power_sum(3, 1, 2, 3)

liefert den Rückgabewert 36, da \(1^3 + 2^3 + 3^3 = 36\).
